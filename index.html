Key Engineering Decisions

Event store is source of truth — read model is derived and fully replayable
Axon deadline fires CancelBooking if payment never arrives — explicit, not a silent assumption
Redis SETNX before acting on each Kafka event — exactly-once under at-least-once delivery
BookingConfirmed is a versioned Pact contract, not an implicit schema agreement
CI: unit ∥ contract ∥ integration → SonarQube in one pipeline
